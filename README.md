# Библиотека книг

Django-приложение для импорта и экспорта информации о книгах в форматах JSON и XML.

## Описание

Учебный проект по дисциплине «Прикладная информатика». Приложение позволяет:
- Добавлять книги через форму с валидацией
- Сохранять данные в JSON или XML
- Загружать готовые файлы на сервер
- Проверять файлы на валидность
- Просматривать все загруженные файлы

## Функциональность

- Форма ввода данных о книге (название, автор, год, жанр, страницы)
- Валидация вводимых данных
- Сохранение в JSON или XML
- Загрузка файлов JSON/XML на сервер
- Проверка файлов на валидность с удалением невалидных
- Безопасная генерация имён файлов (UUID)
- Список всех файлов с возможностью просмотра
- Проверка на пустоту папки

## Технологии

- Python 3.14
- Django 6.1.2
- HTML5 / CSS3
- JSON, XML
- Git

## Установка и запуск

### 1. Клонировать репозиторий

    git clone https://github.com/AArina24/books-library.git
    cd BooksProject

### 2. Создать виртуальное окружение

    py -3 -m venv .venv

Windows:

    .venv\Scripts\activate

Linux/Mac:

    source .venv/bin/activate

### 3. Установить зависимости

    pip install -r requirements.txt

### 4. Применить миграции

    py manage.py migrate

### 5. Запустить сервер

    py manage.py runserver

### 6. Открыть в браузере

http://127.0.0.1:8000/
